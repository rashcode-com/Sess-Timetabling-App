# راهنمای جامع شروع سریع و راه‌اندازی پروژه

این راهنما تمامی پیش‌نیازها، مراحل نصب و فرآیند راه‌اندازی گام‌به‌گام محیط‌های توسعه و تست مونوریپوی **Sess-Timetabling-App** را تشریح می‌کند.

---

## ۱. پیش‌نیازهای محیط اجرا (Prerequisites)

پیش از آغاز کار با پروژه، اطمینان حاصل کنید که ابزارهای زیر بر روی سیستم شما نصب و فعال هستند:

* **Node.js**: نسخه `v20.x` یا بالاتر (نسخه LTS توصیه می‌شود)
* **pnpm**: نسخه `v11.x` یا بالاتر (مدیر بسته‌های رسمی ورک‌اسپیس)
  ```bash
  # فعال‌سازی و نصب آخرین نسخه pnpm از طریق Corepack
  corepack enable
  corepack prepare pnpm@latest --activate
  ```
* **Git**: آخرین نسخه پایدار سیستم کنترل نسخه گیت

> [!CAUTION]
> این پروژه یک **Core-First Monorepo** مدیریت‌شده با **pnpm workspaces** و **Turborepo** است. استفاده از دستورات `npm` یا `yarn` به دلیل ایجاد تداخل در ساختار وابستگی‌های متقابل (Symlinks) اکیداً ممنوع است.

---

## ۲. دریافت مخزن و نصب وابستگی‌ها (Installation)

مخزن گیت را کلون کرده و وابستگی‌های تمام پکیج‌ها و سرویس‌ها را با یک دستور در سطح ریشه مونوریپو نصب کنید:

```bash
# دریافت مخزن پروژه از گیت‌هاب
git clone https://github.com/rashcode-com/Sess-Timetabling-App.git
cd Sess-Timetabling-App

# نصب ساختاربندی‌شده پکیج‌ها در سطح کل ورک‌اسپیس
pnpm install
```

دستور فوق به صورت خودکار پکیج پایه‌ای `@sess/core` را در سایر بسته‌ها لینک کرده و کش ماژول‌ها را سازماندهی می‌کند.

---

## ۳. اجرای سرویس‌ها در محیط توسعه (Development Servers)

شما می‌توانید کل سرویس‌های مونوریپو را به‌طور هم‌زمان اجرا کنید یا بر اساس نیازمندی توسعه، سرویس مشخصی را بالا بیاورید:

### الف) اجرای هم‌زمان تمام سرویس‌ها با Turborepo
```bash
pnpm dev
```
این دستور وب‌اپلیکیشن، مستندات، گیت‌وی API و حالت تماشای هسته را به صورت موازی اجرا می‌کند.

---

### ب) اجرای اختصاصی وب‌اپلیکیشن کلاینت (`@sess/web`)
فرانت‌اند بر روی سرور توسعه پرسرعت **Vite 6** اجرا شده و از طریق آدرس زیر در دسترس خواهد بود:
* **آدرس لوکال:** `http://localhost:8081`

```bash
pnpm web:serve
# یا با استفاده از فیلتر ورک‌اسپیس:
pnpm --filter @sess/web dev
```

---

### ج) اجرای گیت‌وی API (`@sess/api`)

* **اجرا در محیط شبیه‌ساز لبه Cloudflare Workers (پیشنهادی):**
  ```bash
  pnpm api:dev
  ```
  سرویس از طریق ابزار رسمی Wrangler روی آدرس `http://localhost:8787` شبیه‌سازی می‌شود.

* **اجرا بر پایه ران‌تایم محلی Node.js:**
  ```bash
  pnpm --filter @sess/api dev:node
  ```

* **بارگذاری اولیه کاتالوگ در فضای ابری Cloudflare KV:**
  ```bash
  pnpm kv:seed
  ```

---

### د) اجرای پورتال جامع مستندات فنی (`@sess/docs`)
پورتال مستندات بر بستر سرور VitePress با آدرس زیر بالا می‌آید:
* **آدرس لوکال:** `http://localhost:5180`

```bash
pnpm docs:dev
```

---

### ه) اجرای سرویس کراولر پورتال (`@sess/crawler`)
* **اجرای ویزارد تعاملی خط فرمان:**
  ```bash
  pnpm crawler:dev
  ```
* **یا اجرای مستقیم برای یک دپارتمان خاص در پس‌زمینه (Headless):**
  ```bash
  pnpm --filter @sess/crawler dev -- -d 32 --headless
  ```

---

## ۴. اعتبارسنجی استاتیک، تست‌ها و خطایابی (Quality Assurance)

برای حصول اطمینان از سلامت کدهای تغییریافته، پایپ‌لاین تست‌های زیر در دسترس است:

```bash
# ۱. اعتبارسنجی تایپ‌های TypeScript و کامپوننت‌های Vue 3 SFC
pnpm --filter @sess/web type-check

# ۲. اجرای تست‌های واحد ETL، استورهای Pinia و الگوریتم‌های تداخل
pnpm --filter @sess/web test

# ۳. اجرای تست‌های واحد توابع پارسر و نرمال‌سازی متنی کراولر
pnpm --filter @sess/crawler test

# ۴. ثبت و مقایسه اسنپ‌شات‌های رگرسیون تصویری با Playwright
pnpm e2e:baseline
```

---

## ۵. فرآیند کامپایل و بیلد پروداکشن (Production Build)

برای کامپایل و بسته‌بندی تمامی پکیج‌های مونوریپو بر اساس گراف وابستگی‌های Turborepo:

```bash
pnpm build
```

پس از اتمام بیلد:
* فایل‌های استاتیک وب‌اپلیکیشن در `apps/web/dist` قرار می‌گیرند.
* پکیج‌های `@sess/core` و `@sess/api` در پوشه‌های `dist/` خود کامپایل می‌شوند.
* پورتال مستندات در `apps/docs/.vitepress/dist` تولید می‌شود.

برای اجرای یکپارچه فرانت‌اند و API روی سرور محلی یا VPS:
```bash
PORT=3000 NODE_ENV=production pnpm start
```
سپس سامانه در آدرس `http://localhost:3000` در دسترس خواهد بود.
